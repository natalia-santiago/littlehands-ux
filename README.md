# Little Hands Mobile Soft Play Website

A modern, responsive website built for a luxury mobile soft play business. Designed to showcase services, drive bookings, and create a premium online presence.

Live Site

Features

- Fully responsive design (mobile-first)
- Elegant, luxury UI/UX design
- Booking and contact form (Netlify Forms ready)
- Gallery of soft play setups
- Package pricing section
- SMS and Call quick contact buttons
- Instagram integration section
- SEO optimized (metadata, sitemap, robots)
- Smooth animations and hover effects

- Next.js (App Router)
